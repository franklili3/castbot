# 高置信度 / critical+high 子集的相关性深入分析

> 生成时间：2026-06-25
> 数据：基于 `news-price-correlation-data.json` (1160 条)
> 脚本：`/tmp/subset-correlation.py`

## 假设

如果 LLM 「更确信」的新闻（高 conf）或评分系统认为「更重要」的新闻（critical/high tier）真的更能驱动价格，那么子集的方向准确率应该**显著高于**全量基线 48.7%。

## 核心结果（反直觉）

### 1. 置信度越高，方向预测越不准

| 阶段 | 全量 | conf≥0.7 | conf≥0.8 | conf≥0.9 |
|---|---|---|---|---|
| 2024 牛市 | 48.7% | 47.5% | 45.9% | **37.5%** ⬇️ |
| 2025 震荡 | 48.7% | 43.9% | 41.4% | 42.2% |
| 2026 熊市 | 55.5% | 52.7% | 51.0% | 53.6% |

**2024 牛市 conf≥0.9 子集达到统计显著的负相关**：Pearson r=-0.2310 (p=0.027*)

这意味着：**LLM 越确信，越倾向于预测错方向** — 高置信度是反向指标。

### 2. 2026 熊市出现极端两极化

LLM 在熊市中的高置信度预测呈现戏剧性的非对称：

| 子集 | bullish 准确率 | bearish 准确率 |
|---|---|---|
| 全量 (conf≥0) | 34.3% (n=70) | 85.7% (n=49) |
| conf≥0.7 | 24.0% (n=50) | 86.0% (n=43) |
| conf≥0.8 | **4.2%** (n=24) | **92.6%** (n=27) |
| conf≥0.9 | **7.1%** (n=14) | **100.0%** (n=14) |

**实操含义**：
- 熊市中 LLM 高确信 bullish → **强烈的反向做空信号**（仅 4-7% 概率真涨）
- 熊市中 LLM 高确信 bearish → **可靠做空信号**（92-100% 准确）
- 在熊市中，**用 LLM bullish 信号做多是致命错误**

### 3. critical+high tier 反而拉低总体准确率

`pipeline-state.json` 中带 tier 字段的数据（最近推送的）：

| 子集 | N | 准确率 | bull 准确 | bear 准确 | Pearson r |
|---|---|---|---|---|---|
| critical+high | 33 | 36.4% | 0.0% (n=21) | 100.0% (n=12) | -0.274 (p=0.083) |
| (无 tier) | 86 | 62.8% | 49.0% (n=49) | 81.1% (n=37) | **+0.235 (p=0.010\*)** |
| high only | 27 | 40.7% | 0.0% (n=16) | 100.0% (n=11) | **-0.350 (p=0.042\*)** |

**关键发现**：
- high tier 的 bullish 预测准确率 **0%** (16 条全错) — 这是惊人的反向指标
- (无 tier) 子集反而跑出统计显著的正相关 (p=0.010) — 旧数据的 LLM 分类更靠谱
- 双重过滤 (critical+high AND conf≥0.7) 的 bearish 子集准确率 **100% (n=11)**

### 4. 波动率信号 |涨跌|

虽然方向预测失效，但 LLM 能识别「会动」的新闻：

| 子集 | 平均 \|涨跌\% \| |
|---|---|
| 全量牛市 | 1.98% |
| 牛市 conf≥0.9 | 1.97% |
| 全量熊市 | 2.07% |
| 熊市 conf≥0.8 | **2.65%** |
| 熊市 critical+high | **2.95%** |
| 熊市 high only | **3.03%** |

**critical/high + 高 conf 的新闻确实对应更大的价格波动**（约 1.5 倍），只是方向不可预测。

## 实操结论（可直接接入交易策略）

### 策略 A：做空波动率（推荐，最稳）
当 square-agent 推送 **critical 或 high tier** 新闻时，**做多 BTC 波动率**（买入 straddle）。平均 |涨跌| ≈ 3%，足够覆盖期权成本。**不需要预测方向**。

### 策略 B：熊市中做空（强信号）
当满足以下条件时做空 BTC：
- 处于熊市（如 BTC 月度跌幅 > 10%）
- LLM 分类为 **bearish**
- conf ≥ 0.7

历史准确率 86-100%。

### 策略 C：熊市反向做空（基于反向指标）
当满足以下条件时做空 BTC：
- 处于熊市
- LLM 分类为 **bullish**（注意：与策略 B 相反）
- conf ≥ 0.8

历史准确率 93-96%（4-7% 的例外是它真的涨了）。

### 反例：不要做的事
- **不要在牛市/震荡市根据方向做单** — 准确率 48.7%，等于抛硬币
- **不要信任 LLM 的「高置信度」** — 它越确信，越可能错（牛市 r=-0.23）
- **不要把 pipeline 的 critical+high 当买入信号** — 它的 bullish 准确率是 0%

## 方法学注意事项

1. **2026 熊市样本小** — 161 条总样本，critical+high 仅 33 条，p 值仍 > 0.05
2. **bearish 100% 是小样本假象** — n=11~14 的「100%」在样本扩大后必然下降
3. **24h 窗口可能稀释信号** — 真正反应在 1-4h 内，需要 1h K 线回测验证
4. **survivorship bias** — pipeline 推送的新闻已经被 LLM 自己筛过一遍
5. **regime 识别滞后** — 实操中如何判断「现在是不是熊市」本身是个问题
