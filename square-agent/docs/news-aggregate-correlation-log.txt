  - 每日聚合所有文章的 sentiment score → 单个数值
  - 与当日 BTC 涨跌幅做相关
  - 样本量 = 天数 (不是文章数)

我们之前的方法:

  - 样本量 = 文章数

==================================================================================
【关键结论】
==================================================================================

文献 vs 我们的方法学差异是真正的瓶颈：

文献 (Farrugia 2025):
  - 每日聚合 sentiment → 1 个数字
  - 与当日 BTC 涨跌做相关
  - r = 0.21 (p < 0.05) ✅
  - 样本: 90 天

我们之前的方法:
  - 每条文章 → 1 个 sentiment
  - 与该条发布后 24h 涨跌做相关
  - r ≈ 0.05 (p > 0.05) ❌
  - 样本: 1160 篇

每日聚合的优势:
  1. **降噪** - 当日几十条文章相互平均，单条噪音被稀释
  2. **真实信号** - 反映当日整体市场情绪而非单条新闻冲击
  3. **样本量灵活** - n = 天数，与文章数无关
