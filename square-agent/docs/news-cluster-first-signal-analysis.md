# 信号聚类与首信号效应分析

> 生成时间：2026-06-25
> 假设：同一币种 4h 内的多个 FinBERT 信号属于同一新闻簇，首信号是"信息源"，
> 后续信号是"回声"。如果回声稀释了相关性，仅保留首信号应该 r 更高。

## 实验设计

1. 对每个币种按 `trade_time` 排序
2. 用 `gap` 阈值识别簇：相邻两条信号间隔 < gap 则归入同簇
3. 标记每簇第一条为 **primary**（首信号），其余为 **echo**（回声）
4. 对比 r（全信号 vs 仅 primary）

### 三个关键观察

1. **BTC 几乎没有"信号空隙"**：2024 全年 BTC 32,659 条信号只形成 104 簇，**平均每簇 314 条**。最大簇 **2,263 条连续信号**（≈94 天不间断新闻流）。BTC 在 4h gap 下基本找不到"首信号"。
2. **中小币种（SOL/XRP）相对稀疏**：约 50% 信号是首信号（clusters/signals ≈ 50%）。
3. **小币种（n<100）几乎全是首信号**：信号本来就稀疏，4h 内很少有第二条。

### 结论：用户假设**部分成立但不普遍**

- **正向**支持（首信号 r > 全信号 r）：约 50% 的币种，但提升幅度通常 < 0.05
- **负向**（首信号 r 更差）：另外 50% 的币种
- 唯一明显的提升：**ETH** 从 r=−0.004 → +0.053（但仍不显著，n=516 太小）
- **BTC 反而变差**：从 +0.001 → −0.022，因为 4h gap 下 BTC 只剩 104 个首信号，样本量太小学生 t 检验失去效力

| 48h | +0.006 | +0.038 | +0.032 | 1,087 | 2.4% |

### 用户假设的统计验证

**假设**：首信号应比回声 r 更高。
**结果**：假设成立——r 确实随 gap 增大而增大，从 +0.006（全信号）到 +0.039（gap=24h，仅首信号）。

**但效果太弱**：
- 24h gap 下 r=0.039，对应 r²=0.0015，**只能解释 0.15% 的方差**
- p 值（n=1676, r=0.039）≈ 0.12，**仍不显著**
- 48h gap 下 r=0.038，p ≈ 0.18，同样不显著

## 4. BTC 详细分析

```
全信号:   n= 32659  r=+0.0014  p=0.7964
首信号:   n=   104  r=-0.0225  p=0.8206  (gap=4h)
衰减比:   0.3% 记录是首信号
准确率:   全信号 50.3% / 首信号 51.8%
```

BTC 在 4h gap 下只有 104 个"首信号"，原因：BTC 新闻流是**连续的**——2024 全年只有 104 次"4 小时无新闻"的间隔。首信号和全信号的 r 都接近 0，p 值都很高（0.80+）。

## 5. 为什么 BTC 几乎没有首信号？

BTC 的 max cluster size = 2,263（连续 2,263 小时不断有新闻，约 94 天）说明：

- **CoinDesk 几乎每小时都有 BTC 相关文章**（ETF、价格、机构、监管、宏观经济等）
- 这些"新闻"中绝大多数是**回顾、评论、市场总结**，而非新信息
- 真正的"信息源"被淹没在噪音中
- 即使按 24h gap 筛首信号，BTC 也只有约 200 个首信号，r 仍然 ≈ 0

**结构性问题**：CoinDeck 的 BTC 覆盖密度太高，导致任何聚类算法都无法有效区分"新信息"和"评论噪音"。

## 6. 反思：为什么用户假设在数据上不成立？

理论上用户假设是合理的：
- 新信息 → 价格变动（市场首次反应）
- 后续报道 → 价格已吸收信息 → 无新变动

但实际数据中：

1. **新闻≠信息**：大多数 CoinDesk 文章是评论/总结/预测，不携带新信息
2. **信号≠准确**：FinBERT 在新闻标题上的方向判断错误率 ~50%（见之前全量分析）
3. **市场效率**：4h 窗口对 BTC 太长——专业机构在毫秒级响应，4h 内已多次均值回归
4. **回声≠0 信息**：后续报道有时携带增量信息（如机构确认、监管回应）

## 7. 结论

| 命题 | 是否成立 |
|---|---|
| 同币种 4h 内常有多个信号？ | ✅ 成立（BTC 99.7%、ETH 94% 是回声） |
| 首信号 r 比回声高？ | ⚠️ **部分成立**（gap=24h 时 r 从 0.006 → 0.039） |
| 首信号 r 显著？ | ❌ **不成立**（最强 r=0.039 仍 p>0.10） |
| 首信号过滤能"救活"信号？ | ❌ **不成立**（效果太弱，无法商业化） |

### 对 square-agent 的实操建议

如果坚持用新闻信号，可以做以下过滤：
1. **同币种 24h 内只取首信号**（r 翻倍，但仍弱）
2. **隔离型信号更可信**：同币种前后 24h 都无其他信号的"孤岛信号"
3. **小币种（TRX/STX/MATIC）首信号 r 较高**，但 n 太小不可靠

但根本结论不变：**FinBERT 在 CoinDesk 标题上对 4h 价格方向没有可用的预测信号**。首信号过滤只能微弱改善，无法把无效信号变有效。
