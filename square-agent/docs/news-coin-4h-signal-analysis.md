# 49 币种 4h signal-price 相关性分析（严格 open_time 校正版）

> 生成时间：2026-06-25

> **校正**：对 Binance API 的"静默返回上线首日数据"行为做了严格 open_time 校验

## 关键修正：Binance API 的陷阱

初次分析发现 TON |涨跌| 高达 24.83%，明显异常。排查后发现：

```
请求 TONUSDT @ 2024-02-02 18:00 UTC
返回 k[0] open_time=2024-08-08 10:00:00 UTC  open=4.352   ← 实际是上线首日
```

**Binance klines API 行为**：当请求的 `startTime` 早于币种上线时间时，API 不报错也不返回空，而是**静默返回上线首日的 kline 数据**。这导致上线前的所有新闻都被匹配到同一天的虚假价格。

**修复方案**：在拉取时严格校验 `kline[0].open_time` 与请求 `startTime` 一致（5 分钟容差），不一致则标记为无效。

| 指标 | 校正前 | 校正后 |
|---|---|---|
| 有效记录 | 47,528 (98.3%) | 46,528 (96.2%) |
| TON 样本量 | 165（含 87 条假数据） | **72**（仅上线后） |
| TON \|涨跌\| | 24.83%（虚假） | **1.21%**（合理） |
| TON 显著性 | r=+0.26 ✅✅ | r=+0.23 ⚡（边缘） |

类似问题影响：TON（2024-08 上线）、STRK（2024-02 上线）、ENA（2024-04 上线）、SUI（2024-05 上线）、NOT（2024-05 上线）。

## 重大反转：BTC 的 r 从 +0.24（500-sample）→ +0.001（32k 全量）

这是本次分析最关键的发现，必须正视：

| 分析 | BTC n | r | p 值 | 结论 |
|---|---|---|---|---|
| 之前 500-sample 4h FinBERT | 258 | +0.2418 | 0.0001 ✅✅ | Bonferroni 显著 |
| **本次 32k 全量 4h FinBERT** | **32,659** | **+0.0014** | **0.796 ❌** | **零相关** |

**32,659 样本下 r=0.0014 几乎就是 0**——如果原 r=0.24 是真效应，在 n=32k 下 p 值应该 ≪ 10⁻¹⁰⁰。现在 p=0.80 意味着**之前的"显著"完全是采样假象**。

### 为什么差距这么大？

| 因素 | 500-sample | 32k 全量 |
|---|---|---|
| 来源 | HuggingFace coindesk 子集（采样） | CoinDesk 全量 2024 |
| 币种标签 | 原数据 `symbol_used` 字段（人工标注） | 我的 title+categories 自动分类 |
| 样本量 | 258 | 32,659（125×） |
| BTC 定义 | 严格（仅主要主题为 BTC） | 宽松（title/categories 任意提及 BTC） |

### 验证：500-sample 的 r=0.24 可能来源

如果只取 32k 的随机 258 条子集，r 分布应该有 ~5% 概率超过 0.12（单测）。**原 r=0.24 在零假设下概率约 0.0001**——但这是单次抽样。如果我们试了多个子集（牛市/熊市 × 多模型 × 多窗口）然后报告最好的结果，**多重检验偏差**就能解释这个"显著"。

之前的多窗口分析试了 3 regime × 4 窗口 × 2 模型 = 24 组测试， Bonferroni α=0.0021。在零假设下 24 次测试出现至少一次 p<0.0021 的概率为 `1 - (1-0.0021)^24 ≈ 4.9%`——刚好接近 5%。所以即便所有真实 r=0，也有 5% 概率看到至少一个"Bonferroni 显著"结果。

**结论**：500-sample 的 r=0.24 大概率是 false positive。

## 启示：新闻标题 → 4h 价格方向不可预测

经过 7 轮分析（全量/子集/FinBERT/聚合/多窗口/多币种/49 币种全量），结论收敛：

1. **样本量越大，r 越接近 0**（典型的 false positive 衰减曲线）
2. **FinBERT 在 CoinDesk 标题上的信号在 4h 窗口 ≈ 0**
3. **没有任何币种（包括 BTC/ETH/SOL）通过 Bonferroni 校正**
4. **唯一的显著结果（SUI r=+0.28）需要 out-of-sample 验证**

## 对 square-agent 的最终建议

**不要把新闻 LLM 信号用于价格方向预测**。本次 32k 全量分析推翻了之前所有基于小样本的"显著"结论。square-agent pipeline 中 LLM 的角色应该回到：

| 角色 | 是否有效 |
|---|---|
| 内容生成（中文翻译+解读） | ✅ 有效 |
| 重要性筛选（critical/high） | ✅ 有效（波动率筛选用） |
| 价格方向预测 | ❌ 全量数据上无信号 |
| 波动率预测（涨/跌幅度） | ⚠️ 弱有效（critical+high 对应更大波动） |

如继续探索，建议转向：
1. **链上数据**（订单流、巨鲸地址、衍生品持仓）
2. **更细粒度时间窗口**（1min、5min 而非 4h）
3. **多模态**（Twitter 流式 + 新闻，自己抓而非用 CoinDesk 聚合）
