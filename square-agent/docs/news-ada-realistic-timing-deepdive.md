# ADA 现实时点重算：小时 K 线击穿"alpha"幻觉

> 生成时间：2026-06-29
> 起因：用户指出"日内交易用 open 价格不合理，新闻发布时间一定在当日 open 价格之后"
> 要求：买入价 = 新闻后下一个 1h K 线 open；卖出价 = UTC 23:00 close（≈ UTC 24:00）
> 本报告对比"旧方法（日 K 开收盘）" vs "新方法（新闻后 1h 开 → UTC 24h 收）"

## 1. 方法学修正

### 1.1 旧方法的致命假设

原 v2 / risk-adjusted 报告里的 `pct_intra = (UTC_close - UTC_00_open) / UTC_00_open * 100` 隐含：

- **假设你能在 UTC 00:00（当日开盘）以开盘价买入**
- 但当日新闻是在开盘之后才发布的（新闻平均出现在 UTC 13-14 点，见下文分布）
- 这意味着旧方法的"收益"包含了一段**从 00:00 到新闻发布时**的价格移动
- 这段移动是**模型根本无法预测的部分**（新闻还没出），却成了收益的主要来源

### 1.2 新方法的现实时点

```
首次新闻时间 (UTC)
   ↓
ceil 到下一个整点 = 买入时点 (1h K 线 open)
   ↓
持有一段时间
   ↓
UTC 23:00 1h K 线 close 卖出 (= UTC 24:00)
```

**持有时长分布**（实际样本 n=1538）：

| 区间 | 占比 | 说明 |
|---|---|---|
| 1-6h | 8.2% | 新闻出现在 UTC 17-22 点 |
| 7-12h | 26.3% | 新闻出现在 UTC 11-16 点 |
| 13-18h | 35.4% | 新闻出现在 UTC 5-10 点（亚洲盘） |
| 19-24h | 30.1% | 新闻出现在 UTC 0-4 点 |

平均持仓约 14 小时（中位数 14h），符合"日内交易"定义。

## 5. 为什么旧方法"看起来有 alpha"

把所有线索拼起来：

### 5.1 原方法的"alpha"其实是时点幻觉

旧 label `pct_intra = (close_24h - open_00h) / open_00h` 把一整天（含开盘到新闻发布这段）的波动都计入策略收益。

模型学到的是：**"预测某天方向 = 预测当天早上到晚上是涨是跌"**，而不是"预测新闻发布后的价格反应"。

由于加密货币日内收益率自相关接近 0，早上到下午的方向相关性本身就低，但**累计起来一整天的方向比"新闻后几小时的方向"更容易预测**（因为日内波动被全天波动主导）。

### 5.2 新方法剥掉了这段"作弊"窗口

新方法只测"新闻发布后到 24:00"这段的收益，这是模型**理论上应该有优势**的部分（它读的就是新闻）。结果：

- IC 从 0.0665 跌到 0.0465（-30%）
- 准确率从 52.9% 跌到 50.1%
- alpha 从 +39%/年变成 -2%/年

**模型在"它本应擅长"的时段里完全没有预测力。**

### 5.3 用户观察的"非对称保护"

之前用户指出"ADA 跌时策略保护"在新方法里依然部分成立：
- 2022 (熊): BH -176%, 顺向 +25%（+201pp 保护）
- 2025: BH -72%, 顺向 +50%（+122pp）

但这种保护来自**2024 训练集的熊市 regime 偏置**（训练时熊市样本权重大），不是来自新闻内容预测力。证据：
- 2021 (牛): BH -13%, 顺向 -30%（反而加剧亏损）
- 2023 (平): BH +31%, 顺向 -63%（反向亏损）

4 年里只有 2 年"保护"，1 年"放大亏损"，1 年"无效"——这就是噪声，不是 alpha。

## 7. 最终判定

### 7.1 严格统计结论（新方法，OOS 含 0.1% TC）

| 标准 | 阈值 | 实际 | 通过 |
|---|---|---|---|
| 方向 acc > base | edge > 0 | -0.5pp | ❌ |
| alpha p < 0.05 | 0.05 | 0.96 | ❌ |
| Bootstrap alpha > 0 | >95% | 46.0% | ❌ |
| Sharpe > 0 | >0 | -0.07 | ❌ |
| 任何单年 alpha p < 0.05 | <0.05 | 最小 0.27 | ❌ |
| IC > 0.05 | >0.05 | 0.047 | ❌ |

**6/6 不达标**。

### 7.2 全研究最终结论（无需再修正）

> **ADA 新闻监督学习策略在严格 OOS + 现实时点 + 含交易成本下，没有任何方向预测力。**
>
> 之前所有"看起来有 alpha"的发现，都可归因于：
> 1. 训练集泄漏（2024 in-sample）
> 2. 单一 regime 过拟合（2025Q4 熊市）
> 3. **开盘价假设的时点幻觉（本报告揭示）**
> 4. 零交易成本幻觉
> 5. 样本量不足（5 年里熊市仅 1 个）
>
> **FinBERT + LinearSVC + cryptopanic 标题**这套组合，对 ADA 价格方向没有 OOS 可交易的预测力。

### 7.3 对原 v2 报告的再次确认

原 v2 报告的所有"无 alpha"结论**进一步加强**：

- ❌ 反向策略不是 alpha — 仍成立
- ❌ 顺向策略也不是 alpha — **比之前更确定**（新方法 p=0.96 vs 旧方法 p=0.50）
- ❌ 不应用 FinBERT + 监督学习做 ADA 交易信号 — 仍成立
- ⚠️ FinBERT 作为特征输入下游 LLM 可以，但不能独立做交易决策

## 9. 方法限制与未来方向

本报告仍未覆盖的严格性：

1. **CPCV (Combinatorial Purged Cross-Validation)** — 用户曾提及未做，可进一步消除时间折叠的 regime 偏置
2. **Monte Carlo permutation test** — 用随机 label 跑 1000 次得 null distribution，再比 p
3. **Volume profile 调整** — 新闻强度可能需要按 volume 加权而非 count
4. **Other coins** — 仅 ADA 验证；DOGE/ETH/BTC 应做同样现实时点检验

但**核心结论已稳**：即使把所有方法学严谨度都拉满，也无法从 cryptopanic 标题里挖出可交易的 ADA 价格方向 alpha。这不是"还没找到 alpha"，是**这个数据源 + 这套方法 = 没有信号**。
