## 2. 关键发现

### 2.1 仅 SUI 同时满足"准确率高 + 统计显著"

| 指标 | SUI | 其他高准确率币 |
|---|---|---|
| 2h 准确率 | **57.7%** | INJ 76% / MATIC 62.4% / TRX 61.7% |
| n | 71 | 25/117/107 |
| 统计显著 | **✅ p=0.0004** | ❌/⚡ p=0.077/❌ |

SUI 是唯一在小样本下达到 r=0.40 双星显著的币种。其他高准确率币种要么 n 太小（INJ 25），要么 r 太弱（MATIC/TRX 的 |涨幅| 太小，Pearson 检测不到）。

### 2.2 OP / UNI / AVAX 系统性判错（<45%）

| coin | 准确率 | 含义 |
|---|---|---|
| op | 40.7% | 65 次预测中 38 次反向 |
| uni | 41.8% | 57 次预测中 33 次反向 |
| avax | 44.7% | 52 次预测中 29 次反向 |

FinBERT 对这些代币的新闻方向判断系统性错误。可能原因：
- **OP**：Optimism 升级/融资新闻常被分类为 bullish，但市场已 price-in
- **UNI**：Uniswap 治理提案常被分类为 bullish，但实际无实质影响
- **AVAX**：Avalanche 生态新闻的代币指向不清（常与 BTC/ETH 联动）

### 2.3 主流币完全随机（50%±0.5%）

| coin | 准确率 | n_eff |
|---|---|---|
| btc | 50.0% | 12,327 |
| eth | 49.8% | 4,182 |
| xrp | 49.8% | 887 |

BTC 在 12,000+ 有效样本下准确率 50.0%，**统计学上等同于抛硬币**。这是对 FinBERT 在 BTC 价格预测上的最终判决。

### 2.4 准确率与显著性的脱节

MATIC 准确率 62.4% 但仅边缘显著（p=0.077）：
- 原因：MATIC 的 |2h涨幅| 平均仅 0.73%
- 大多数预测正确的样本，价格变动很小，Pearson r 检测不到
- 准确率高 ≠ 相关性强（高方差样本里的小波动也算"正确"）

## 4. 结论

| 命题 | 是否成立 |
|---|---|
| FinBERT 能预测 2h 涨跌方向？ | ⚠️ 整体 50.3%，等同抛硬币 |
| 部分小币准确率 >60%？ | ✅ 成立（MATIC/TRX/NEAR/INJ） |
| 高准确率 = 可商用？ | ❌ 不成立（除 SUI 外都不显著或样本太小） |
| 主流币有任何方向预测力？ | ❌ 不成立（BTC/ETH 准确率 50%） |
| OP/UNI/AVAX 是反向指标？ | ✅ 成立（准确率 <45%） |

### 核心结论

- **方向准确率与相关性的脱节**：MATIC 62.4% 准确率看似可观，但 |涨幅| 太小，统计上仍边缘显著（p=0.077）
- **SUI 是唯一赢家**：57.7% 准确率 + p=0.0004，但 n=71 集中在 2024 下半年
- **主流币无任何方向预测力**：BTC 12,000+ 样本下准确率 50%，是 FinBERT 的最终判决
- **OP/UNI/AVAX 是反向信号源**：可考虑反向操作（但 n 不足，需更多数据验证）
