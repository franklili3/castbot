【统计功效分析】需要多少样本？
==================================================================================

场景1: 检测论文典型效果 (r=0.20-0.27)
Effect r   α=0.05/双侧      α=0.004/Bonferroni  
--------------------------------------------------
r=0.300    n = 85           n = 148
r=0.250    n = 124          n = 216
r=0.200    n = 194          n = 340
r=0.150    n = 347          n = 609
r=0.100    n = 783          n = 1378
r=0.088    n = 1012         n = 1781
r=0.050    n = 3138         n = 5529

解读:
- 想检测 r=0.20 (文献典型): 需 194 个有方向预测的样本
- 想检测 r=0.088 (我们 2026 熊市的实际 r): 需 1015 个
- 经过 Bonferroni 校正 (12 个测试): 数值翻倍以上

==================================================================================
【论文方法论的关键启示】
==================================================================================

1. **专用模型 >> 通用 LLM**
   - Farrugia 用 FinBERT+FinancialBERT: r=0.21-0.39 ✅
   - Hurjui 用 RNN+syuzhet: r=0.22 ✅
   - 我们用 GLM-4.5 通用 chat: r=-0.05~0.09 ❌
   → 切换到 FinBERT 是最高 ROI 的改进

2. **Twitter/Reddit 比新闻更强**
   - Hurjui: Reddit 对 BTC/ETH/ADA 都显著 Granger cause
   - Multimodal (2025): TikTok 短期、Twitter 长期都对预测有 alpha
   - 单看新闻只覆盖机构视角，缺散户情绪
   → 加入社交数据是必要扩展

3. **价格窗口有讲究**
   - Farrugia: 0h→12h→24h，效果递增 (r=0.29→0.39)
   - 我们用 24h 是对的，但应增加 4h、8h 多窗口对比
   - Hurjui: daily+4day lag 也显著
   → 当前 24h 单一窗口 OK，但应做多窗口

4. **小样本的补救**
   - Lamon 仅 3,600 标题 + 67 测试日就报「有效」，但只是 in-sample
   - Farrugia 1,300 篇 + 90 天就达显著，但用了 FinBERT
   - 结论: <1000 样本要显著，必须用专用模型
