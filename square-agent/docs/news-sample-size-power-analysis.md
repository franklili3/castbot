# 样本量需求分析：从论文基准到统计功效

> 生成时间：2026-06-25
> 基于 5 篇加密货币情绪-价格相关性论文 + 统计功效计算

## 核心问题

之前的多市场阶段分析得出**所有结论都不达统计显著** (p>0.05)。两个可能原因：
1. 样本量不够
2. 模型选择错误

本文档基于文献基准 + 功效分析给出定量答案。

## 文献基准：5 篇论文用什么样本量达到显著？

| 论文 | 样本量 | 周期 | r | 显著? | 方法 |
|---|---|---|---|---|---|
| Lamon (CS229 2017) | 3,600 标题 + 30K 推文 | 11 个月 | ? | ❌ | LR/SVM/NB + n-grams |
| **Farrugia (2025)** | **1,300 篇** | **90 天** | **+0.21** | **✅** | **FinBERT+FinancialBERT** |
| Hurjui (2022) | 21.9M 推文/帖 | 1 年 | +0.22 | ✅ | intotheblock RNN |
| FinBERT-BiLSTM (2024) | 585 天数据 | 1.5 年 | ? | ? | FinBERT + BiLSTM |
| Multimodal (2025) | 519K 推文+15K TikTok | 2.3 年 | ? | ✅ | Llama-3-8B + MiniGPT4 |

**文献关键发现**：
1. 最小达统计显著的样本：**Farrugia 用 1,300 篇 / 90 天**就达到 r=0.21 (p<0.05)
2. 典型效果大小：**r = 0.20-0.27** (small-to-moderate)
3. 最强效果：**r = 0.39** (Farrugia ETH @ 24h)
4. **没有一篇用通用 chat LLM 直接跑相关性**
5. 主流价格窗口：**24h / 1day**（我们用的 24h 是对的）

## 统计功效计算（Fisher z 变换）

公式：`n ≈ ((Z_α/2 + Z_β) / atanh(r))² + 3`，α=0.05，power=0.80

| 想检测的效果 | α=0.05 (常规) | α=0.004 (Bonferroni 校正) |
|---|---|---|
| **r=0.30 (Farrugia ETH 最强)** | **85 条** | 148 条 |
| r=0.25 | 124 条 | 216 条 |
| **r=0.20 (文献典型)** | **194 条** | 340 条 |
| r=0.15 | 347 条 | 609 条 |
| r=0.10 | 783 条 | 1378 条 |
| **r=0.088 (我们 2026 熊市的实际 r)** | **1015 条** | 1781 条 |
| r=0.05 (我们 2024/2025 的实际 r) | 3138 条 | 5529 条 |

## 文献方法论的关键启示

### 1. 专用模型 >> 通用 LLM
- Farrugia 用 FinBERT+FinancialBERT：r=0.21-0.39 ✅
- Hurjui 用 RNN+syuzhet：r=0.22 ✅
- 我们用 GLM-4.5 通用 chat：r=-0.05 ~ +0.09 ❌
- **结论**：切换到 FinBERT 是最高 ROI 的改进

### 2. Twitter/Reddit 比新闻更强
- Hurjui：Reddit 对 BTC/ETH/ADA 都显著 Granger cause
- Multimodal (2025)：TikTok 短期、Twitter 长期都有 alpha
- 单看新闻只覆盖机构视角，缺散户情绪
- **结论**：社交数据是必要扩展

### 3. 价格窗口有讲究
- Farrugia：0h→12h→24h，效果递增（r=0.29→0.39）
- 当前 24h 单一窗口 OK，但应增加 4h、8h 多窗口对比

### 4. 小样本的补救
- Lamon 仅 3,600 标题 + 67 测试日就报「有效」，但只是 in-sample
- Farrugia 1,300 篇 + 90 天就达显著，但用了 FinBERT
- **<1000 样本要显著，必须用专用模型**
